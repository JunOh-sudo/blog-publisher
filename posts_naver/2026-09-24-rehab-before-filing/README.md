# 발행 패키지: 개인회생 신청 전 반드시 멈춰야 할 행동 5가지 (T006)

상태: **비공개 발행 준비 완료 · 변호사 에디터 검수 대기**
검수 결과: compliance 반려 사유 3건(R1~R3) 편집장 반영 완료 → 남은 것은 변호사 법리 확인뿐

## 파일
| 파일 | 용도 |
|---|---|
| `preview.html` | 이미지가 들어간 완성 미리보기 (이미지 위치·대체텍스트·캡션 표시) |
| `body_paste.html` | 스마트에디터에 붙여넣을 본문 (브라우저로 열어 전체 선택 → 복사) |
| `images/` | 대표 이미지 1장 + 본문 이미지 4장 |
| `meta.md` | 제목 후보, 카테고리, 해시태그 30개, 대체텍스트, AI 삽화 프롬프트 |

## 스마트에디터 발행 순서 (약 10분)
1. 네이버 블로그 → 글쓰기. 제목: `개인회생 신청 전 반드시 멈춰야 할 행동 5가지 | 가족 빚 먼저 갚아도 될까`
2. `body_paste.html`을 브라우저로 열어 전체 선택(Ctrl/Cmd+A) → 복사 → 에디터 본문에 붙여넣기
3. `[이미지 N 삽입: 파일명]` 줄마다 그 줄을 지우고 [사진]으로 해당 파일 업로드
   - 이미지 1·3은 삽화: 아래에 캡션(선택) 입력 — preview.html 참고
   - 사진 설정에서 대체텍스트 입력 (meta.md 표)
4. `rehab-before-filing-thumbnail.png`도 올리고 **대표 사진**으로 지정 (본문 맨 위 또는 끝)
5. 카테고리: 개인회생·파산 / 태그: meta.md의 해시태그 30개
6. **공개 설정: 비공개**로 저장 → 아래 검수 → 문제 없으면 공개 전환
7. 공개 후 편집장에게 URL 전달 → `published_posts.csv` 기록, 24시간 뒤 네이버 노출 확인(`/blog-index`)
