# 발행 패키지: 한정승인 절차·기간 가이드 (T005, 티스토리)

상태: **비공개 발행 준비 완료 · 변호사 에디터 검수 대기**
검수: compliance 반려 사유 4건(R1~R4) 편집장 반영 완료, 🟡 7건 반영. 남은 것은 변호사 법리 확인.

## 파일
| 파일 | 용도 |
|---|---|
| `post.html` | 티스토리 **HTML 모드**에 붙여넣을 본문 (이미지 자리 `{{IMAGE_1}}`~`{{IMAGE_5}}`, FAQ JSON-LD, 상담 팝업 포함) |
| `preview.html` | 이미지가 들어간 미리보기 |
| `images/` | 대표 1 + 본문 5장 (삽화 3장은 대체 렌더판) |
| `meta.md` | 제목(4번 채택), 카테고리 "상속", 태그 10개, 대체텍스트, AI 삽화 프롬프트 |

## 발행 방법 (택1)
**A. 자동(권장)** — 변호사 PC의 Claude Code + Claude in Chrome:
```
/blog-publish posts_tistory/2026-09-24-limited-acceptance-guide
```
카카오 로그인만 직접 하면 비공개 저장까지 진행합니다.

**B. 수동**
1. ohbhs.tistory.com/manage/newpost → 제목: `한정승인 절차·기간 가이드 | 재산목록 작성법`
2. 에디터 우측 상단에서 **HTML** 모드 → `post.html` 전체 붙여넣기
3. 기본 모드로 돌아와 `{{IMAGE_N}}` 자리마다 이미지 업로드로 교체
   | 자리 | 파일 |
   |---|---|
   | IMAGE_1 | limited-acceptance-illust-1.png (삽화) |
   | IMAGE_2 | limited-acceptance-compare.png |
   | IMAGE_3 | limited-acceptance-illust-2.png (삽화) |
   | IMAGE_4 | limited-acceptance-steps.png |
   | IMAGE_5 | limited-acceptance-illust-3.png (삽화) |
   (또는 `streamlit run app.py`의 Supabase 업로드로 URL 치환 후 붙여넣기)
4. 대표 이미지: limited-acceptance-thumbnail.png / 카테고리: 상속 / 태그 10개(meta.md)
5. **비공개** 저장 → 검수 → 공개 전환 → 편집장에게 URL 전달(`/blog-index`로 Google·네이버·다음 색인 요청)

> 참고: 스크립트(상담 팝업, FAQ JSON-LD)가 저장 후 사라지면 티스토리 설정에서 HTML 편집 시 스크립트 허용 여부를 확인하세요. 팝업이 없어도 본문 상담 링크는 동작합니다.
