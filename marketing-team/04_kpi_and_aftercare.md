# 04. 성과 측정 & 사후관리

## 1. KPI 트리

```
최종 목표: 블로그 경유 수임 건수
 └─ 상담 전환 (엑스퍼트 상담 신청 · 전화 · 카톡 문의)
     └─ 유입 품질 (의뢰 의도 키워드 유입, 체류시간, CTA 클릭)
         └─ 노출 (색인율, 목표 키워드 순위, 노출수)
             └─ 활동 (발행 수, 리프레시 수, 발행 준수율)
```

| 레벨 | 지표 | 12주 목표(초기값) | 데이터 출처 |
|---|---|---|---|
| 활동 | 발행 준수율 | 36건 계획 대비 90%↑ | `published_posts.csv` |
| 활동 | 리프레시 | 월 2~4건 | `published_posts.csv` |
| 노출 | 색인율 | 발행 7일 내 95%↑ | 네이버 서치어드바이저, Google Search Console |
| 노출 | 목표 키워드 상위 노출 | 네이버 VIEW/스마트블록 1페이지 10개 키워드 | 수동 순위 체크 → `keyword_rank.csv` |
| 유입 | 월 방문자 | 기준선 측정 후 +50% | 네이버 블로그 통계, GA4/티스토리 통계 |
| 유입 | 검색 유입 비중 | 70%↑ | 동일 |
| 전환 | CTA 클릭 | 글당 클릭률 1%↑ | UTM 링크 + 엑스퍼트 통계 |
| 전환 | 블로그 경유 상담 | 월 N건(기준선 후 설정) | `leads.csv` (상담 시 “어떻게 알고 오셨나요?”) |
| 성과 | 블로그 경유 수임 | 월 N건 | `leads.csv` |

### UTM 규칙 (상담 링크에 부착)
`?utm_source=naver_blog|tistory&utm_medium=blog&utm_campaign=<pillar>&utm_content=<post_slug>`
(네이버 엑스퍼트가 파라미터를 무시하면 → 글마다 다른 상담 상품/카톡 채널 문구로 대체 추적)

## 3. 리포트 주기

| 주기 | 리포트 | 내용 |
|---|---|---|
| 주간(금) | `reports/weekly-YYYY-WW.md` | 발행 현황, Top 5 글, 신규 유입 키워드, 이상징후(색인 누락·급락), 다음 주 제안 |
| 월간 | `reports/monthly-YYYY-MM.md` | 기둥별 성과, 전환 퍼널, 리프레시 효과, 백로그 재채점 |
| 분기 | 전략 회고 | 기둥 비중 조정, 플랫폼 역할 재검토 |

## 4. 사후관리 규칙 (content-refresher)

| 트리거 | 조치 |
|---|---|
| 공개 당일 | publisher가 색인 요청(티스토리: Google·네이버·다음), 네이버 블로그는 노출 확인만 |
| 발행 3일·7일 후 | publisher가 색인 확인·기록 |
| 발행 7일 후 미색인 | content-refresher가 원인 점검 후 재요청(네이버 누락 의심 시 수정 재발행은 변호사 승인) |
| 글 수정·갱신 | 재색인 요청 |
| 30일: 노출 있음 & 클릭률 낮음 | 제목·도입부 재작성 (검색어 반영) |
| 90일: 순위 11~30위 | 내용 보강(FAQ·표·사례 추가) + 내부링크 3개 추가 |
| 순위·유입 3개월 연속 하락 | 최신화 리프레시 |
| **법령 개정·판례 변경·기준액 변경** | 해당 키워드 전 글 검색 → 즉시 수정 + “최종 업데이트: YYYY.MM.DD” 표기 |
| 동일 키워드 글 2개 이상 | 통합(카니발리제이션 해소) |
| 댓글·안부글 질문 | 일반론 답변 + 상담 안내 (개별 사건 판단 공개 답변 금지) |

### 연간 정기 점검 캘린더
- **1월**: 기준중위소득·생계비 변경 → 개인회생 글 일괄 갱신
- **1월/7월**: 민법·채무자회생법 등 시행일 도래 개정 확인
- **명절 직후(설·추석)**: 상속분쟁 콘텐츠 재노출(상단 고정·SNS 공유)
- **12월**: 연간 결산 글 + 전체 글 링크 점검
