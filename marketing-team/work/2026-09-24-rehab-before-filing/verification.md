# 변호사 확인표: 개인회생 신청 전 반드시 멈춰야 할 행동 5가지

기준일: 2026-09-24 · 근거 정리표: `factsheet.md`

**사용법:** 각 행의 "원고에 쓸 문장"이 맞으면 판정에 `○`, 고칠 곳이 있으면 `수정`과 함께 고친 문장을, 빼야 하면 `삭제`를 적어 주세요.
네트워크가 열리면 리서처가 원문과 먼저 대조하고, 결과를 "리서처 대조" 열에 적습니다. 모든 행이 `○` 또는 `수정`(반영 완료)이면 사실 확인 게이트를 통과합니다.

## 1. 원고에 들어갈 사실 (12건)

| # | 행동/파트 | 원고에 쓸 문장 (쉬운 말) | 근거 | 리서처 대조 | 판정 |
|---|---|---|---|---|---|
| 1 | ① 편파변제 | 신청 전에 특정 채권자(가족·지인 포함)에게만 갚으면, 그 금액이 청산가치에 더해져 매달 갚을 돈이 늘어날 수 있습니다. 그것만으로 곧바로 기각되는 것은 아닙니다. | 채무자회생법 제584조(제100조 준용), 대법원 2010. 11. 30.자 2010마1179 결정 | | |
| 2 | ① 편파변제 | 개인회생 부인권은 개시결정일부터 1년 안에 행사할 수 있습니다. *(원고에 넣을지 여부도 판단해 주세요)* | 제584조 | | |
| 3 | ② 재산 처분 | 신청 전에 차·부동산·보증금 등을 가족 명의로 돌리거나 헐값에 팔면, 부인권 행사 대상이 되거나 원래 가치대로 청산가치에 반영될 수 있습니다. | 제584조, 제100조 제1항 | | |
| 4 | ② 재산 처분 | 재산목록을 사실과 다르게 적으면 개시신청이 기각될 수 있습니다. | 제595조 (해당 호 번호 기재 요망) | | |
| 5 | ③ 현금 인출·송금 | 법원은 통장 거래내역을 보고 큰 금액의 인출·이체에 대해 사용처 설명을 요구할 수 있습니다. 보정 요구에 응하지 않으면 불리해질 수 있습니다. *(제출 기간 숫자는 쓰지 않음)* | 법원 보정 실무, 대법원 2017. 2. 17.자 2016마1324 결정 | | |
| 6 | ④ 신규 대출 | 신청 직전의 새 대출·돌려막기·현금서비스는 법원이 경위 소명을 요구할 수 있고, 채권자 이의의 근거가 될 수 있습니다. 다만 대법원은 '성실하지 아니한 경우'를 이유로 한 기각을 좁게 봅니다. | 제595조 제7호, 대법원 2015. 9. 1.자 2015마657 결정 | | |
| 7 | ⑤ 투자·도박 | 신청을 준비하면서 새로 주식·코인에 투자하거나 도박하는 것은 멈춰야 합니다. *(행동 지침 중심)* | 일반 원칙 | | |
| 8 | ⑤ 투자·도박 (보충) | 서울회생법원은 주식·가상화폐 투자로 이미 잃은 돈을 원칙적으로 청산가치에 넣지 않는 기준(실무준칙 제408호, 2022. 7. 1. 시행)을 두고 있습니다. 예외가 있고 법원마다 다를 수 있습니다. | 서울회생법원 실무준칙 제408호 (**현행 여부**, 2026.4 개정설) | | |
| 9 | 대신 이렇게 | 추심·압류가 걱정되면 개인회생 신청과 함께 중지명령·금지명령을 신청할 수 있습니다. 법원이 명령을 내려야 효력이 생깁니다. | 제593조 | | |
| 10 | 대신 이렇게 | 개시결정이 나면 개인회생채권에 기한 강제집행 등은 중지·금지됩니다. | 제600조 | | |
| 11 | 대신 이렇게 | 개인회생은 무담보채무 10억 원, 담보채무 15억 원 이하인 급여소득자·영업소득자가 신청할 수 있습니다. | 제579조 (2021. 4. 20. 시행 상향, 현행·한시 여부) | | |
| 12 | 대신 이렇게 | 이미 한 변제·이체는 숨기지 말고 신청서에 적고 소명자료를 준비하세요. | 일반 원칙 | | |

## 2. 원고에서 뺀 것 (확인 불필요)
- 신청 전 이혼·재산분할: 공식 근거 부족, 사안별 판단 → 별도 글 후보
- 거래내역 제출 기간, "최근 채무 ○%" 같은 숫자: 공식 출처 없음
- 파산 면책불허가(제564조)와 도박: 개인회생 글과 섞지 않음

## 3. 변호사 판단 요청
- [ ] 5개 구성 확정 (⑤를 "보험 무단 해지·퇴직금 중간정산 후 사용"으로 바꿀지)
- [ ] 실무 경험상 덧붙일 주의점 (선택, 1~2줄)
