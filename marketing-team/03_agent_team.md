# 03. 에이전트 팀 구성 (추천안)

## 1. 조직도

```
                    ┌──────────────────────────────┐
                    │  오준성 변호사 (최종 승인권자)    │  ← 사람: 주제 승인 · 법리 최종 검수 · 공개 전환
                    └──────────────┬───────────────┘
                                   │
                    ┌──────────────▼───────────────┐
                    │  편집장 (메인 Claude 세션)       │  ← CLAUDE.md + /blog-* 명령으로 전체 지휘
                    └──┬─────────┬─────────┬───────┘
          ① 기획        │ ② 제작    │ ③ 검수·발행 │ ④ 측정·사후관리
   ┌────────────────┐ ┌─▼──────────────┐ ┌▼───────────────┐ ┌────────────────────┐
   │topic-strategist│ │legal-researcher│ │compliance-     │ │performance-analyst │
   │ 주제·키워드·캘린더│ │ 법령·판례 팩트시트│ │reviewer 법리·광고│ │ 주간/월간 성과 리포트 │
   └────────────────┘ ├────────────────┤ ├────────────────┤ ├────────────────────┤
                      │naver-writer    │ │publisher       │ │content-refresher   │
                      │tistory-writer  │ │ 패키징·발행체크   │ │ 리프레시·내부링크·법개정│
                      └────────────────┘ └────────────────┘ └────────────────────┘
```

에이전트 정의 파일: `.claude/agents/*.md` (Claude Code가 자동 인식)

## 2. 역할 정의

| 에이전트 | 단계 | 입력 | 산출물 | 사용 스킬/도구 |
|---|---|---|---|---|
| `topic-strategist` | 기획 | 백로그, 성과 리포트, 시즌·법개정 | 주간 발행안 3건 + 키워드 세트 + 채점표 | WebSearch, `topic_backlog.csv` |
| `legal-researcher` | 제작 | 확정 주제 | `factsheet.md` (조문·판례·기준액, 출처·확인일) | WebSearch/WebFetch(law.go.kr, 대법원 종합법률정보) |
| `naver-writer` | 제작 | 팩트시트 + 키워드 | 네이버 원고(MD/HTML) + 검수용 DOCX + 이미지 프롬프트 | `legal-blog-automation` 스킬 |
| `tistory-writer` | 제작 | 팩트시트 + 키워드 | 티스토리 `post.html` + `meta.md` | `tistory-blog-automation` 스킬, `app.py` |
| `compliance-reviewer` | 검수 | 원고 + 팩트시트 | 검수 리포트(🔴차단/🟡수정/🟢통과) + 수정본 | 변호사 광고규정 체크리스트 |
| `publisher` | 발행 | 승인된 원고 | 비공개 발행 패키지, 발행 로그(`published_posts.csv`) | `app.py` 5단계, 색인 요청 체크리스트 |
| `performance-analyst` | 측정 | `data/*.csv` 통계 | 주간 리포트, 다음 주 제안 | Read/Bash(csv 집계) |
| `content-refresher` | 사후관리 | 발행 로그 + 성과 + 법개정 | 리프레시 티켓, 내부링크 맵 | Grep, WebSearch |

## 3. 표준 워크플로우 (주간 사이클)

| 요일 | 단계 | 담당 | 사람 개입 |
|---|---|---|---|
| 월 오전 | `/blog-plan` → 이번 주 3건 주제·키워드 확정 | topic-strategist | ✅ **주제 승인(5분)** |
| 월~화 | `/blog-write <주제>` → 팩트시트 → 원고 → 컴플라이언스 검수 | researcher → writer → reviewer | |
| 화~목 | 변호사 검수(DOCX/미리보기) → 비공개 발행 → 공개 전환 | publisher | ✅ **법리 최종 검수(글당 15~20분)** |
| 발행 +1일 | 네이버 서치어드바이저·GSC 색인 요청, 발행 로그 기록 | publisher | |
| 금 | `/blog-report` → 주간 성과 리포트 | performance-analyst | 👀 열람 |
| 매월 말 | `/blog-refresh` → 리프레시 2~4건 + 내부링크 보강 | content-refresher | ✅ 승인 |

### 품질 게이트 (통과 못 하면 다음 단계 진행 불가)

1. **G1 팩트 게이트**: 모든 조문·판례·금액에 출처 + 확인일. 불확실 항목은 `[확인필요]` 표시 → 해소 전 발행 금지.
2. **G2 컴플라이언스 게이트**: 🔴 항목 0건 (아래 체크리스트).
3. **G3 변호사 게이트**: 변호사 승인 없이 **공개 전환 금지**. 에이전트는 비공개 발행까지만.

## 4. 컴플라이언스 체크리스트 (compliance-reviewer 기준)

- 🔴 “전문/전문변호사/전문가”(변협 전문분야 등록 분야 외), “최고·최초·유일·1위”, 승소율·수임건수 과장
- 🔴 결과 보장 표현(“무조건”, “100%”, “반드시 면책”)
- 🔴 성공사례: 의뢰인 동의 없는 사례, 식별 가능한 정보(사건번호·실명·지역+직업 조합 등)
- 🔴 타 변호사·법인 비방·비교
- 🔴 사건 기록·의뢰인 문서 내용 인용 (Drive에 실사건 자료가 섞여 있으므로 **원고 작성에 실사건 파일 사용 금지**)
- 🟡 면책 공고 누락, 법령 기준일 누락, 상담 유도 문구 과다
- 🟡 네이버: 동일 키워드 과다 반복, 외부링크 과다, 타 플랫폼 글과 유사도
- 🟢 광고책임변호사 표시, “법무법인 강호 오준성 변호사” 도입부, 상담 링크 정상

## 5. 운영 모드 선택

| 모드 | 설명 | 추천 대상 |
|---|---|---|
| **A. 반자동 (추천)** | 에이전트가 기획~비공개 발행까지, 변호사는 승인 2회(주제·최종) | 지금 단계. 품질·광고규정 리스크 관리 |
| B. 자동 초안 | 주제 백로그에서 매일 초안만 자동 생성(Routine), 발행은 수동 | 원고 재고를 쌓고 싶을 때 |
| C. 완전 자동 | 권장하지 않음 | 법률 광고 특성상 사람 검수 필수 |

## 6. 시작 방법

```bash
# 저장소 루트에서 Claude Code 실행 후
/blog-plan                  # 이번 주 주제 3건 제안
/blog-write 상속포기 기간     # 팩트시트 → 네이버/티스토리 원고 → 검수
/blog-report                # data/ 통계로 주간 리포트
/blog-refresh               # 월간 리프레시·내부링크 점검
```
